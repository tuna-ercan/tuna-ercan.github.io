How I Made This Website

Welcome!

  On this page, I described "How I Made This Simple Website". First of all, I want to explain to you why rather than how.

Why?

  I'm a person who really likes sharing knowledge and motivating people who have an interest in robotics, programming, etc. One day I came with an idea; Making a blog-like website where I can share my hobby-work (tech stuff). So, in the short term, I made it for helping others and a bit for motivating my self.

How?

  When I decided to do it, I needed to learn some important things. Like how to make a website? So I jumped on youtube to find some tutorials. I found this tutorial. While I was following the tutorial i kept googling things that didn't make up in my mind. I finished the tutorial, nice but now what? I opened photoshop and made some page samples, then I "coded" it. "Oops, I don't know how I can make this element, okey it's google time!". While I was searching a tutorial, found this channel and I learned a lot of new design strategies and new components from it. It was looking good but there were still some problems. "OnlineTutorials"s tutorials were good but they weren't so clear and understandable so I ended up with an another google time and used this website for learn more. Another problem was this: I COULDN'T CENTER COMPONENTS. Solution: display:grid + place-items:center (found in here). The website was done but domain&hosting wasn't. For this, thank you github.io. It's a hosting service from GitHub and it is very simple to use.
